# OpenTV-Cast 0.2.1 — public preview

AirPlay receiver for Android TV, Google TV and Android boxes. Mirror from an iPhone, iPad or Mac on the same local network. This is a debug-signed test build; hardware compatibility and motion smoothness still need broader testing.

## Included
- OpenTV-Cast name, TV/signal icon and banner.
- Independent mirroring decoder-output draining and dedicated frame callbacks, with renderer lifecycle regression checks.
- Universal APK: ARM64, ARM32 and x86_64; minimum Android API 23.
- Existing local TV Bridge/OpenTV-Cast test builds retain their upgrade signing identity and saved settings.

## Install
Download the APK, open it on your TV using its downloads/file manager, allow installation from that app if prompted, and confirm Install. Open OpenTV-Cast, start the receiver, then choose it under Screen Mirroring on the Apple device. Both devices must be on the same local network. USB copy or `adb install -r` are alternatives.

## Limits
DRM-protected content is unsupported. This APK does not turn arbitrary boxes into Chromecast devices. Experimental Cast Connect requires external setup and a compatible sender. Android 6.0+ is the install minimum, not a guarantee of compatibility with every TV. Builds made by other developers/CI may have a different signer.

Build, lint, unit tests, renderer lifecycle checks and emulator startup checks have passed during development. Actual TV smoothness and broad iPhone/Mac compatibility still require hardware acceptance. Please include device/OS versions and mirroring versus streaming mode in issue reports.
